## Regras de interpretação

- CORE: invariância/centro.
- PRINCIPAL_AXIS: comparação de polos.
- FACE: estado direcional.
- EDGE: interface entre duas direções.
- VERTEX: convergência de três direções.
- BODY_DIAGONAL: transformação de polaridades do cubo inteiro.
- OPPOSITE_EDGE_AXIS: reconciliação entre interfaces complementares.
